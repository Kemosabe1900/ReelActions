# Chat / RAG Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Add a streaming SSE chat endpoint that does RAG over the user's transcript chunks, routes to Haiku or Sonnet based on query length, and persists messages to the DB.

**Architecture:** `ChatService` owns RAG lookup + model routing + Claude streaming; `app/api/chat.py` owns the HTTP layer, wraps the service generator in a `StreamingResponse`, and writes both turns to `chat_messages` after the stream closes. The client sends history with each request — server is stateless on the inference path.

**Tech Stack:** FastAPI `StreamingResponse`, Anthropic streaming API (`messages.stream`), `text-embedding-3-small` via existing `EmbeddingService`, supabase-py, pytest

### Task 1: ChatService

**Files:**
- Create: `app/services/chat.py`
- Create: `tests/test_chat_service.py`

The service takes a message, history, and user_id. It calls `embedder.search_similar()` (already built — returns list of `{video_url, video_title, content, ...}`), builds a Claude prompt, streams the response, and yields event dicts. The route consumes these dicts.

`stream_response()` yields two event types:
- `{"type": "delta", "text": "..."}` — one per streamed text chunk from Claude
- `{"type": "sources", "urls": [{"url": "...", "title": "..."}]}` — once, after the stream, deduplicated by URL

If Claude raises mid-stream: yield `{"type": "error", "detail": "..."}` and return early (sources event is skipped).

```python
from typing import Generator, Optional
from anthropic import Anthropic
from app.config import settings
from app.services.embedder import get_embedding_service

SYSTEM_PROMPT = (
    "You are a personal knowledge assistant. The user has saved TikTok and Instagram Reels "
    "to build a knowledge base. Answer their question using only the context provided below — "
    "excerpts from their saved video transcripts. Be concise and specific. "
    "If the context doesn't contain enough information to answer, say so."
)


class ChatService:
    def __init__(self):
        self.client = Anthropic(api_key=settings.anthropic_api_key)
        self.embedder = get_embedding_service()

    def _select_model(self, message: str) -> str:
        return "claude-haiku-4-5-20251001" if len(message) <= 200 else "claude-sonnet-4-6"

    def stream_response(
        self,
        message: str,
        history: list[dict],
        user_id: str,
    ) -> Generator[dict, None, None]:
        chunks = self.embedder.search_similar(message, user_id, limit=5)

        context_parts = [f"[{c['video_title']}]\n{c['content']}" for c in chunks]
        context = "\n\n".join(context_parts) if context_parts else "No relevant videos found."

        seen_urls: set[str] = set()
        sources = []
        for c in chunks:
            if c["video_url"] not in seen_urls:
                seen_urls.add(c["video_url"])
                sources.append({"url": c["video_url"], "title": c["video_title"]})

        messages = [
            *[{"role": m["role"], "content": m["content"]} for m in history],
            {"role": "user", "content": f"Context:\n\n{context}\n\nQuestion: {message}"},
        ]

        model = self._select_model(message)

        try:
            with self.client.messages.stream(
                model=model,
                max_tokens=1024,
                system=SYSTEM_PROMPT,
                messages=messages,
            ) as stream:
                for text in stream.text_stream:
                    yield {"type": "delta", "text": text}
        except Exception as e:
            yield {"type": "error", "detail": str(e)}
            return

        yield {"type": "sources", "urls": sources}


_chat_service: Optional[ChatService] = None


def get_chat_service() -> ChatService:
    global _chat_service
    if _chat_service is None:
        _chat_service = ChatService()
    return _chat_service
```

The route wraps `chat_service.stream_response()` in a `StreamingResponse`. The inner generator:
1. Iterates events from the service, serialising each as `data: <json>\n\n`
2. Appends text from `delta` events, captures the `sources` event
3. After the last service event, yields `data: [DONE]\n\n`
4. Writes user message + assistant response to `chat_messages` table

`TestClient` buffers the full stream body synchronously, so the DB writes (which happen inside the generator after `[DONE]`) are complete by the time `response` is returned in tests.

```python
import json
from fastapi import APIRouter, Depends
from fastapi.responses import StreamingResponse
from pydantic import BaseModel
from app.dependencies import get_current_user
from app.database import get_db
from app.services.chat import get_chat_service

router = APIRouter(tags=["chat"])


class ChatMessage(BaseModel):
    role: str
    content: str


class ChatRequest(BaseModel):
    message: str
    history: list[ChatMessage] = []


@router.post("/chat")
def chat(
    body: ChatRequest,
    user_id: str = Depends(get_current_user),
):
    chat_service = get_chat_service()

    def generate():
        full_response: list[str] = []
        source_list: list[dict] = []

        for event in chat_service.stream_response(
            body.message,
            [m.model_dump() for m in body.history[-6:]],
            user_id,
        ):
            if event["type"] == "delta":
                full_response.append(event["text"])
            elif event["type"] == "sources":
                source_list = event["urls"]
            yield f"data: {json.dumps(event)}\n\n"

        yield "data: [DONE]\n\n"

        db = get_db()
        db.table("chat_messages").insert({
            "user_id": user_id,
            "role": "user",
            "content": body.message,
            "video_sources": [],
        }).execute()
        db.table("chat_messages").insert({
            "user_id": user_id,
            "role": "assistant",
            "content": "".join(full_response),
            "video_sources": source_list,
        }).execute()

    return StreamingResponse(generate(), media_type="text/event-stream")
```
