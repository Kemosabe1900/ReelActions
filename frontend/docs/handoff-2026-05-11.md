## Backend API Reference

Base URL: configured in backend `.env`

| Method | Path | Purpose |
|--------|------|---------|
| POST | `/api/v1/videos` | Submit URL for processing |
| GET | `/api/v1/videos` | List saves (filter: category, tried) |
| GET | `/api/v1/videos/{id}` | Single video + structured data |
| PATCH | `/api/v1/videos/{id}/tried` | Toggle tried status |
| GET | `/api/v1/jobs/{id}` | Poll job status |
| GET | `/api/v1/profile` | User profile + explorer stats |
| POST | `/api/v1/chat` | SSE streaming RAG chat |
